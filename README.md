# FMCG Supply Chain Analytics Dashboard

## 📌 Overview
Power BI project aimed at analyzing and improving supply chain performance for **Atliq Mart**.

## 🎯 Objectives
- Monitor supply chain KPIs
- Identify service-level gaps
- Enable data-driven decision-making

## 🛠️ Tools
- Power BI
- DAX
- Excel

## 📊 KPIs Analyzed
- OTIF (On-Time In-Full)
- LIFR
- VOFR

## 🚀 Key Contributions
- Built dashboards covering **3 cities & 50+ product categories**
- Created **20+ DAX measures** for root cause analysis
- Identified **15% service delivery gap**
- Provided actionable insights through trend analysis
